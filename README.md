# 12V to 5V DC Converter

## Overview
This project is a 12V to 5V DC-DC buck converter PCB design created with KiCad. The converter allows you to efficiently step down 12V DC power sources to 5V for powering various electronic devices and circuits.

## Features
- Input voltage: 12V DC
- Output voltage: 5V DC
- Buck converter topology for efficient power conversion
- Compact PCB design
- Ready for production

## Directory Structure
- `fabrication-toolkit-options.json` - Configuration for fabrication toolkit
- `PCB design Course.kicad_pcb` - KiCad PCB layout file
- `PCB design Course.kicad_sch` - KiCad schematic file
- `PCB design Course.kicad_pro` - KiCad project file
- `database/` - Project database files
- `PCB design Course-backups/` - Automatic backup files
- `production/` - Manufacturing files (Gerbers, BOM)

## Getting Started
1. Install [KiCad](https://www.kicad.org/download/)
2. Open `PCB design Course.kicad_pro` to view and modify the project
3. Use the schematic editor to view the circuit design
4. Use the PCB editor to view the board layout

## Manufacturing
The production directory contains all necessary files for manufacturing the PCB.
